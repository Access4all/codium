Linktexte in Listen

Oft werden Links unter angefangenen Inhalten aufgeführt, die zum Weiterlesen oder Weiterschauen weiterführen. Sind die Link-Texte nur "Weiterlesen" oder "Weiterschauen", dann sind die Links für Screenreader-Nutzende nicht immer verständlich.

Dieses Problem kann gelöst werden, indem ein solcher Link innerhalb eines Parent-Elementes liegt, das den Kontext für diesen Link bessert klärt. Beispielsweise durch eine Liste:

  • Test-Item 1

    Hier steht ein wenig Text als Beispiel, wer mehr Informationen dazu haben möchte, kann den unteren Link verwenden.

    Weiterlesen

  • Test-Item 2

    Hier steht ein wenig Text als Beispiel, wer mehr Informationen dazu haben möchte, kann den unteren Link verwenden.

    Weiterlesen

  • Test-Item 3

    Hier steht ein wenig Text als Beispiel, wer mehr Informationen dazu haben möchte, kann den unteren Link verwenden.

    Weiterlesen

Linktexte in Paragraphen

Auch können Links (oft auch visuell als Schalter gestylt) direkt innerhalb eines Paragraphen liegen, damit der Kontext für einen ansonsten nicht verständlichen Linktextes zu geben.
